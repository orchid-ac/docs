Orchid's terminal UI is fully keyboard-driven. Every shortcut below is configurable - see [Configuration](/cli/configuration) for how to override one in your config file.

<Info>
  `<leader>` means press **Ctrl+X**, release, then press the next key. It's the default leader - press `?` inside a session for the live, always-current list from your actual config.
</Info>

## Interaction mode and agents

The interaction mode toggle is the fastest way to control how cautious Orchid is, independent of which agent is active.

| Shortcut | Action |
|---|---|
| `Shift+Tab` | Cycle interaction mode: normal → auto-accept edits → plan → normal |
| `<leader>a` | Open the agent list |
| `Ctrl+Shift+Tab` | Previous agent |
| `<leader>m` | List available models |
| `Ctrl+T` | Cycle model variants (reasoning effort) |
| `F2` / `Shift+F2` | Next / previous recently used model |

**Normal** runs as usual, asking before risky actions. **Auto-accept edits** skips confirmation on file edits. **Plan** drafts a plan and asks for approval before touching anything - see [Plan mode](/cli/features#plan-mode).

## Application

| Shortcut | Action |
|---|---|
| `Ctrl+C`, `Ctrl+D`, or `<leader>q` | Exit Orchid |
| `Ctrl+P` | Open the command palette |
| `<leader>t` | List themes |
| `<leader>b` | Toggle sidebar |
| `<leader>e` | Open external editor |
| `<leader>s` | View status |

## Sessions

| Shortcut | Action |
|---|---|
| `<leader>n` | New session |
| `<leader>l` | List all sessions |
| `<leader>g` | Show session timeline |
| `<leader>c` | Compact the session |
| `<leader>x` | Export session to editor |
| `<leader>q` | Manage queued prompts |
| `Ctrl+R` | Rename session |
| `Ctrl+D` | Delete session |
| `Ctrl+F` | Pin or unpin session in the session list |
| `Ctrl+B` | Background running subagents |
| `Escape` | Interrupt the current session |
| `<leader>1` through `<leader>9` | Jump to a pinned quick-switch slot |
| `Up` / `Down` | Go to parent / next child session |
| `Right` / `Left` | Go to next / previous child session |

## Messages

| Shortcut | Action |
|---|---|
| `Page Up` / `Page Down` | Scroll messages by a page |
| `Ctrl+Alt+U` / `Ctrl+Alt+D` | Scroll messages by half a page |
| `Ctrl+G` / `Ctrl+Alt+G` | Jump to first / last message |
| `<leader>y` | Copy a message |
| `<leader>u` / `<leader>r` | Undo / redo a message |
| `<leader>h` | Toggle code block concealment |

## Prompt input

Standard readline-style editing works in the prompt box:

| Shortcut | Action |
|---|---|
| `Return` | Submit |
| `Shift+Return`, `Ctrl+Return`, `Alt+Return`, or `Ctrl+J` | Insert a newline without submitting |
| `Ctrl+A` / `Ctrl+E` | Jump to start / end of line |
| `Alt+F` / `Alt+B` | Move a word forward / backward |
| `Ctrl+W` | Delete the word before the cursor |
| `Ctrl+K` / `Ctrl+U` | Delete to end / start of line |
| `Ctrl+-` (or `Cmd+Z` on macOS) | Undo in the input field |
| `Up` / `Down` | Recall previous / next prompt from history |
| `Tab` | Complete the current autocomplete suggestion |

## Diff viewer

| Shortcut | Action |
|---|---|
| `Escape` or `q` | Close the diff viewer |
| `Enter` / `Space` | Toggle a diff item |
| `Right` / `Left` | Expand / collapse a diff item |
| `E` | Expand all folders |
| `]` / `[` | Next / previous hunk |
| `n` / `p` | Next / previous file |
| `b` | Toggle the file tree |
| `v` | Toggle split or unified view |
| `?` | Show more diff-viewer shortcuts |
