---
title: "Event kinds"
description: "The built-in kinds Orchid records, their fields, and what each counts as."
---

Your own kinds start with `x.` ([Event types](/send/event-types)). These are the built-in kinds you will meet most. A key may send the ones marked **you send**; Orchid writes the rest.

**Counts as**: A = activity, W = work, C = comms, G = governance.

## AI use

| Kind | `attrs` | Counts as |
| --- | --- | --- |
| `ai.message` | `role` (required), `surface`, `model` | A, W, G |
| `ai.request` | `model`, `provider`, `input_tokens`, `output_tokens`, `latency_ms`, `status_code`, `cost_usd`, `saving_usd`, `baseline_model`, `route`, `agent`, `run` | A |
| `ai.tool_call` | `tool` (required), `system`, `action`, `outcome` | A |

## Communications and systems

| Kind | `attrs` | Counts as |
| --- | --- | --- |
| `mail.message` | `folder`, `direction`, `labels` | A, C, G |
| `chat.message` | `channel` | A, C, G |
| `calendar.event` | `starts_at`, `ends_at` | A, C |
| `file.version` | `path`, `size` | C, G |
| `meeting.transcript` | | A, C, G |
| `system.record` (**you send**) | `system`, `record_id` | A, G |

## Your agents

| Kind | `attrs` | Counts as |
| --- | --- | --- |
| `dev.agent.run` (**you send**) | `agent`, `status` (required), `duration_ms`, `model`, `input_tokens`, `output_tokens`, `cost_usd`, `minutes_saved`, `work_type`, `version` | A, W |
| `dev.agent.metric` (**you send**) | `agent`, `name`, `value` (required), `unit`, `run` | |
| `dev.agent.feedback` (**you send**) | `agent`, `label` (required), `score`, `run` | W |
| `dev.tool_call` (**you send**) | `system`, `action` (required), `outcome`, `agent`, `run` | A, G |

## Governance

| Kind | `attrs` |
| --- | --- |
| `rule.matched` | `rule_id`, `outcome` (required), `rule`, `where`, `matched` |
| `alert.changed` | `alert_id`, `status` (required), `action`, `assignee`, `note`, `disposition` |
| `budget.crossed` | `budget_id`, `state` (required: `warning` or `reached`), `spent_usd`, `monthly_usd`, `scope` |

## Work

| Kind | `attrs` | Counts as |
| --- | --- | --- |
| `work.task` | `work_type`, `minutes` (estimated), `outcome`, `turns` | W |
| `employee.run` | `employee_id` (required), `run_id`, `status`, `step`, `version` | A, W |
| `insight.action.changed` | `action_id`, `status` (required), `change` | |

## Webhooks

| Kind | `attrs` |
| --- | --- |
| `webhook.failed` | `subscription_id` (required), `event_id`, `status`: a delivery was given up and its webhook paused |

`GET /v1/record/kinds` returns every kind your firm records, with each kind's schema, and your own kinds after it.
