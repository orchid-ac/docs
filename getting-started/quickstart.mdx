---
title: "Quickstart"
description: "Send an event from your own agent, read it back, and see what it cost, in ten minutes."
---

You need to be an admin of your firm in Orchid for the first two steps. After that, everything runs with the key.

## 1. Define an event type

Your own kinds of event are named `x.<something>`, in lower case. Go to **Admin › Developers › Event types › New type**, or call the admin API with your console session:

```bash
curl -X PUT https://app.orchid.ac/v1/org/event-types/x.deal_desk.approval \
  -H "Authorization: Bearer $ORCHID_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
        "title": "Deal desk approval",
        "counts_as": ["activity", "governance"],
        "schema": {"type": "object",
                   "properties": {"amount": {"type": "number"}, "desk": {"type": "string"}},
                   "required": ["amount"]}
      }'
```

`counts_as` decides what Orchid does with the events without any further code. `governance` means your firm's rules run on their text. See [Event types](/send/event-types).

If you only want to report your agents' runs, skip this step: the built-in [agent kinds](/send/agents) need no definition.

## 2. Add a connection and make a key

Go to **Admin › Developers › Send your own events › Add**. Name it after what will send the events, such as "Pricing agents". You get a key (`osk_...`). Copy it now: it cannot be shown again.

A new key can send events and read back its own. To read cost or alerts, or to make webhooks, make a key with more [scopes](/getting-started/keys-and-scopes).

```bash
export ORCHID_KEY=osk_...
```

## 3. Send events

```bash
curl https://app.orchid.ac/v1/events \
  -H "Authorization: Bearer $ORCHID_KEY" \
  -H "Content-Type: application/json" \
  -d '{"events": [
        {"kind": "dev.agent.run", "ref": "run-8812", "occurred_at": "2026-11-26T10:00:00Z",
         "actor": "j.smith@yourfirm.com", "thread": "run-8812",
         "attrs": {"agent": "pricer", "status": "ok", "duration_ms": 41200, "minutes_saved": 40}},
        {"kind": "x.deal_desk.approval", "ref": "appr-17", "occurred_at": "2026-11-26T10:01:00Z",
         "actor": "j.smith@yourfirm.com", "thread": "deal-442",
         "text": "Approved at 9.5x EBITDA against three comparables.",
         "attrs": {"amount": 12500000, "desk": "credit"}}
      ]}'
```

```json
{"recorded": 2, "duplicates": 0}
```

Send the same batch again and you get `{"recorded": 0, "duplicates": 2}`: an event is identified by its kind, `ref` and time, so a retry is never counted twice.

## 4. Read it back

```bash
curl "https://app.orchid.ac/v1/events?kinds=dev.agent.run" -H "Authorization: Bearer $ORCHID_KEY"
```

The events also appear in the console: in the audit log, in people's activity, and under your rules.

## 5. See what your agent cost

When your agent calls models through Orchid's gateway, add two headers, and Orchid counts what each run cost:

```python
from openai import OpenAI

llm = OpenAI(base_url="https://app.orchid.ac/v1", api_key=ORCHID_API_KEY,
             default_headers={"X-Orchid-Agent": "pricer", "X-Orchid-Run": "run-8812"})
```

Then, with a key that has `metrics:read`:

```bash
curl https://app.orchid.ac/v1/agents/pricer -H "Authorization: Bearer $ORCHID_KEY"
```

See [Agents](/send/agents) and [Cost and savings](/read/cost).
